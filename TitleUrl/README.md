# 网页金句生成器

一个简单的 Chrome 浏览器扩展，可以将网页中的文字内容转换为精美的图片。

## 功能描述

### 基础功能
- 用户可以手动复制网页中的文字，粘贴到插件的输入框中
- 支持多行文本输入
- 生成竖版图片，高度根据文本内容自适应

### 图片样式
- 默认图片尺寸：宽度固定 800px，高度自适应
- 支持自定义文字样式：
  - 字体大小
  - 字体颜色
  - 文字描边颜色
  - 字幕区域高度

### 操作流程
1. 在网页中选中并复制想要的文字内容
2. 点击 Chrome 工具栏中的插件图标
3. 将文字粘贴到插件弹出窗口的输入框中
4. 调整文字样式参数
5. 点击"生成字幕"按钮预览效果
6. 点击"保存图片"按钮下载生成的图片

### 图片效果
- 文字居中显示
- 背景半透明黑色遮罩
- 文字支持描边，提升可读性
- 每行文字独立显示，自动换行

## 技术规范
- 使用 Manifest V3 开发
- 支持主流浏览器
- 轻量级设计，不影响浏览器性能
- 符合 Chrome Web Store 发布要求

## 后续优化方向
1. 添加更多背景样式模板
2. 支持直接在网页中选中文字后右键生成
3. 添加更多字体选项
4. 支持自定义背景图片
5. 添加更多图片尺寸比例选项

## 使用限制
- 仅支持文本内容
- 暂不支持特殊字符和emoji
- 单次生成图片的文字长度建议不超过 200 字
